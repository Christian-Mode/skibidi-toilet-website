# AI Minecraft Addon Generator

A powerful web application that generates fully functional Minecraft Bedrock Edition addons using AI-powered generation. Transform your ideas into working Minecraft addons with just a few clicks!

## 🚀 Features

- **Multiple Addon Types**: Generate custom items, mobs, blocks, abilities, dimensions, structures, biomes, recipes, loot tables, and command functions
- **AI-Powered Generation**: Creates complete behavior packs, resource packs, and functions using advanced AI algorithms
- **Comprehensive Output**: Generates project structure, behavior pack JSON, resource pack JSON, Minecraft functions, and installation instructions
- **Interactive UI**: Modern, responsive design with tabbed output and real-time preview
- **Download Addons**: Export your generated addons as downloadable .mcpack files
- **Asset Preview**: Preview your addon details and features before downloading

## 🛠️ How to Use

1. **Open the Application**: Simply open `index.html` in your web browser

2. **Select Addon Type**: Choose the type of addon you want to create
   - Custom Item
   - Custom Mob
   - Custom Block
   - Ability/Spell
   - Custom Dimension
   - Custom Structure
   - Custom Biome
   - Custom Recipe
   - Loot Table
   - Command Function

3. **Choose Addon Features**: Select one or more features from:
   - Custom Textures
   - Custom Sounds
   - Particle Effects
   - Animations
   - Loot Drops
   - Crafting Recipes
   - AI Behavior
   - Commands

4. **Describe Your Addon**: Provide a detailed description of what you want your addon to do

5. **Add Details**: Enter an addon name, select a category, and choose Minecraft version

6. **Generate**: Click the "Generate Addon" button and watch the AI create your addon!

7. **Explore Output**: View your generated addon across multiple tabs:
   - **Project Structure**: Complete file and folder organization
   - **Behavior Pack**: JSON configuration for addon behavior
   - **Resource Pack**: JSON configuration for addon resources
   - **Functions**: Minecraft commands and functions
   - **Installation**: Step-by-step setup guide

8. **Take Action**: Download your .mcpack file, preview assets, or regenerate with different options

## 🔧 Technical Details

### AI Services Integration
The generator is designed to integrate with various AI services:

- **Text-to-Code**: Converts descriptions into Minecraft commands
- **Pixel Art Generation**: Creates custom textures and sprites
- **Sound Generation**: Produces custom sound effects
- **UUID Generation**: Ensures unique identifiers for all addon elements

### Minecraft Bedrock Edition Compatibility
- **Format Version**: 2 (latest addon format)
- **Minimum Engine Version**: 1.18.0+
- **Supported Versions**: 1.18.0, 1.19.0, 1.20.0, 1.20.50+
- **Features**: Holiday Creator Features enabled

### File Structure
Generated addons follow the official Minecraft Bedrock Edition addon structure:
```
addon_name/
├── behavior_pack/
│   ├── manifest.json
│   ├── entities/
│   ├── items/
│   ├── loot_tables/
│   ├── recipes/
│   ├── functions/
│   └── animations/
└── resource_pack/
    ├── manifest.json
    ├── textures/
    ├── sounds/
    ├── texts/
    └── animations/
```

## 🎮 Minecraft Integration

### Installation Steps
1. Download the generated .mcpack file
2. Open Minecraft Bedrock Edition
3. Go to Settings → Storage → Behavior Packs
4. Import the downloaded file
5. Enable "Holiday Creator Features" in world settings
6. Activate both behavior and resource packs
7. Start your world and enjoy your new addon!

### In-Game Usage
- Use `/function namespace:main` to load the addon
- Use `/function namespace:help` for help information
- Follow the generated installation instructions for best results
